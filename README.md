# Student-Management-System
Student Management System
# 🎓 Smart Student Management System

A modern desktop-based Student Management System developed using **Python**, **CustomTkinter**, and **SQLite**. This application helps educational institutions efficiently manage student records through an intuitive graphical user interface.

---

## ✨ Features

### 👨‍🎓 Student Management

* Add Student Records
* Update Student Information
* Delete Student Records
* Search Students by Name
* View All Students

### 💾 Database Management

* SQLite Database Integration
* Automatic Data Storage
* Persistent Student Records

### 🎨 Modern User Interface

* Built using CustomTkinter
* Clean Dashboard Layout
* Interactive Student Table
* User-Friendly Design

Make sure you have:

* Python 3.10+

* VS Code

## Installation

### 1️⃣ Clone Repository

```bash
git clone https://github.com/Lakshithak28/first_project.git
```

### 2️⃣ Open Project Folder

```bash
cd first_project
```

### 3️⃣ Install Required Package

```bash
pip install customtkinter
```

### 4️⃣ Run Application

```bash
python main.py
```
